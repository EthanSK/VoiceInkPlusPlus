Setup

No Agent Flow account or subscription. Bring your own OpenAI API key for live words.

  1. Download, unzip, and move Agent Flow to Applications.
  2. Allow Microphone and Accessibility when asked.
  3. Add an OpenAI API key with API billing for GPT Live transcription. Your ChatGPT subscription doesn't include API credit.
  4. Finish setup, which also downloads a local model for transcription without a key.

Auto-send presses Return after pasting. It starts off; enable it per app in Modes if you want it. For Codex CLI or Claude Code, configure the terminal or editor it runs in.

Updates aren't automatic yet. New versions are on GitHub releases.

Setup guide and app support

Controls

Use your keyboard shortcut or a mapped mouse button.

  • Press once to start, then again to stop and paste.
  • Press twice while recording to finish without pasting. The text stays on your clipboard and in History.
  • Press three times while recording to pause, then once to resume.
  • Start another recording while the last one is still transcribing.
Next Track and saved inputs

While the recorder is visible, Next Track won't skip music. During recording, it stops and sends the text to the input where you started. After a normal stop, while transcription is still running, it can instead choose the input focused now.

These saved-input actions use that app's settings and show an error if the target can't be verified. A normal stop simply pastes into the input focused when the result arrives.

Destination guide

Build from source

Needs macOS 14.4 or later, Xcode and Git.

git clone https://github.com/EthanSK/AgentFlow.git
cd AgentFlow
./scripts/install-first-use.sh
  • Builds Agent Flow, installs it in ~/Applications and opens it. It won't replace an existing installation.
  • Use --all to also install the Codex context skill and YouTube helper. Chrome still needs its unpacked extension loaded manually.
  • The upstream voiceink Homebrew cask installs VoiceInk, not Agent Flow.
